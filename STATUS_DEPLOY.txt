CONFIGURACAO NO SERVIDOR (HOSTINGER)
=================================================================

1. Document Root: Apontar para /public

2. Criar arquivo .env com:
   - APP_ENV=production
   - APP_DEBUG=false
   - APP_URL=https://seudominio.com
   - Credenciais MySQL
   - APP_KEY (gerar com: php artisan key:generate)

3. Permissoes:
   chmod -R 755 storage
   chmod -R 755 bootstrap/cache

4. Executar (via SSH):
   chmod +x deploy.sh
   ./deploy.sh

   OU manualmente:
   php artisan migrate --force
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
